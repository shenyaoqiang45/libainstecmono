# 仿真

浏览器里的运动学仿真，不经过 ROS，也不打开真机。`cd ui && npm install && npm run dev` 后打开 http://localhost:5173 。页眉「仿真」是人形探索，「抓取」是桌面协作臂。

## 人形探索

场景是一间带桌、柜、柱和箱子的房间。人形只在地面上平移和转向，四肢按步态摆动，没有动力学。头部装有一台虚拟 Ainstec 相机，内参与 mock 后端一致，便于和 [model.md](model.md) 的样本对照：

| 量 | 值 |
| --- | --- |
| 分辨率 | 640×512 |
| fx, fy | 500, 500 |
| 主点 | 图像中心 (320, 256) |
| 深度 | 沿光轴的距离，毫米（`depth_scale_m = 0.001`） |
| 安装 | 头顶附近，朝机器人正前方 |

大约每 0.45 秒渲染一次彩色和深度。深度是视线方向的距离（线性编码，不受色调映射影响），再按针孔模型投到世界系。点云以 4 cm 体素累积，已经占用的体素不再写入，颜色按高度上色，便于和房间表面区分。界面上的有效深度计数是这一帧里落在近远平面之间的像素数。

自动探索默认开启：正前方大约 1 m 内有障碍，或这一步会被挡住时，就朝更空的一侧连续转一小段，再继续前进。方向键或 WASD 会暂时接管，松开后若仍勾选自动探索则继续。碰撞是水平面包围盒，人不会穿墙或家具。

右侧面板提供「挑战模式」开关，用于模拟真实主动 3D 传感器的典型失效：

- **材质效果**：暗面（高吸收）和金属（高反射）像素按概率丢失；玻璃在深度通道中被隐藏，因而无深度。
- **环境光噪声**：环境光越强，深度噪声越大，按距离平方放大。
- **双机主动干扰**：开启后噪声放大，模拟两台主动相机同时照明的串扰。

场景里部分障碍物和工件已标记为暗面 / 金属 / 玻璃，可直接观察这些开关对深度图和点云的影响。关闭所有开关即回到理想针孔几何。

这是几何预览，不是物理引擎，也没有把 `pyainstec.Sample` 从 Python 进程接进页面。真机时间戳、标定快照和零拷贝视图仍在 `pyainstec` 里。

## 桌面抓取

协作臂立在桌边，四个转动关节：基座偏航、肩、肘、腕俯仰。腕俯仰把夹爪保持朝下。腕部 Ainstec 相机光轴沿夹爪接近方向。内参与上面的表相同，近平面 0.03 m、远平面 1.5 m，便于看清桌面。

循环是：在桌面上方观察，把高出桌面的深度点聚成一团，对上最近的未抓取物体；移到上方、下降、闭合、抬起，再放进料盒。闭合时夹爪中心离物体足够近，物体才跟着夹爪走。「复位」把物体放回原位并重新开始。

同样没有动力学和碰撞求解。够不着的目标会放弃这一下，回到观察。右侧面板同样提供「挑战模式」开关，部分工件已标记为暗面 / 金属，可观察材质丢失和噪声对抓取检测的影响。
